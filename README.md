# 🍽️ MealMind – Mobile Frontend

MealMind is a modern mobile application built with **Flutter** and **Dart**, designed to make cooking easier, smarter, and more accessible.

The application provides an intuitive user experience for discovering recipes, generating AI-powered meal ideas, managing favorite recipes, and organizing shopping lists.

## ✨ Features

- **Modern Authentication** – Login, registration, email verification, and password recovery.
- **AI Recipe Generation** – Generate personalized recipes based on available ingredients.
- **Recipe Discovery** – Browse, search, and explore recipes.
- **Favorites Management** – Save and manage favorite recipes.
- **Shopping List** – Organize ingredients and manage shopping items.
- **User Profile** – Manage personal information, profile picture, and account settings.
- **Premium Subscription** – Access premium features and manage purchases.
- **Modern UI/UX** – Responsive interface, custom components, loading animations, and smooth navigation.

## 🛠️ Technologies

- Flutter
- Dart
- Dio – API communication
- Provider / ChangeNotifier – State management
- Google Sign-In – Authentication
- Image Picker – Image selection
- Shimmer – Loading animations
- RevenueCat – Subscription management

## 📱 Platform

- Android
- iOS (planned / depending on implementation)

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd mobile
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Configure the backend API URL in the API client.

5. Run the application:

   ```bash
   flutter run
   ```

## 🎯 Project Goal

MealMind aims to simplify everyday cooking by combining an intuitive mobile experience with AI-powered recipe discovery and practical meal organization tools.
